## 2. Is the proxy separable?

**It is a separate network crate, but not a ready standalone proxy.** The local Cargo checkout matches the pin. `microsandbox-network` exports its packet engine, frame queues and poll loop, while `TlsProxy` itself is private, channel-based and coupled to shared network state. The engine also depends on `msb_krun`. [crate exports](https://github.com/superradcompany/microsandbox/blob/09df3d4b9d832adaede1fb9a198cfc660bfab8cd/crates/network/lib/lib.rs#L17-L61), [TLS interface](https://github.com/superradcompany/microsandbox/blob/09df3d4b9d832adaede1fb9a198cfc660bfab8cd/crates/network/lib/engine/tls/proxy.rs#L43-L81), [dependencies](https://github.com/superradcompany/microsandbox/blob/09df3d4b9d832adaede1fb9a198cfc660bfab8cd/crates/network/Cargo.toml#L15-L65).

- **Explicit `HTTPS_PROXY`: adaptation required.** Existing CONNECT code forwards CONNECT to another proxy and intercepts the resulting tunnel; it is not a standalone listening CONNECT server. A standalone version needs a listener, transport adaptation or TLS-core extraction, destination/SNI/HTTP-authority validation, CA provisioning and host-only secret lifecycle control. **UNVERIFIED:** an existing supported standalone `msb` mode or successful VZ deployment. [CONNECT handling](https://github.com/superradcompany/microsandbox/blob/09df3d4b9d832adaede1fb9a198cfc660bfab8cd/crates/network/lib/engine/tcp/proxy.rs#L621-L768).

- **VZ Ethernet gateway: plausible reuse seam.** Inference: a VZ adapter could feed raw frames into the existing public rings/poll loop. It must separately provision macOS addressing, gateway and DNS because MicroSandbox currently supplies those through agentd bootstrap. CA trust, per-computer policy, updates and cleanup also need integration. **UNVERIFIED:** compilation, compatibility and performance of that adapter. [public poll interface](https://github.com/superradcompany/microsandbox/blob/09df3d4b9d832adaede1fb9a198cfc660bfab8cd/crates/network/lib/engine/netstack/poll.rs#L213-L247), [bootstrap network](https://github.com/superradcompany/microsandbox/blob/09df3d4b9d832adaede1fb9a198cfc660bfab8cd/crates/network/lib/engine/network.rs#L475-L517).

## 4. Host-side options for VZ guests

| Option | Evidence and trade-offs |
|---|---|
| **Reuse patched MicroSandbox** | Preserves Silo’s existing substitution, GitHub selector and revocation behavior. The raw Ethernet seam is more directly exposed than the TLS core. Costs: VZ transport adapter, guest networking/bootstrap, lifecycle integration and existing krun dependencies. Apache-2.0 permits reuse; standalone support remains **UNVERIFIED**. [engine interface](https://github.com/superradcompany/microsandbox/blob/09df3d4b9d832adaede1fb9a198cfc660bfab8cd/crates/network/lib/engine/netstack/poll.rs#L213-L247), [license](https://github.com/superradcompany/microsandbox/blob/09df3d4b9d832adaede1fb9a198cfc660bfab8cd/Cargo.toml#L52-L57). |
| **Explicit proxy plus guest CA** | Mitmproxy supplies a standalone regular proxy, macOS distribution, CA handling and request-header addons. Silo still needs per-computer identity, credential selection and live revocation integration. Cooperative clients require proxy configuration; applications can bypass it, so this alone does not reproduce enforced gateway policy. [proxy modes](https://docs.mitmproxy.org/stable/concepts/modes/), [installation](https://docs.mitmproxy.org/stable/overview/installation/), [header addons](https://docs.mitmproxy.org/stable/addons/examples/#example-commands-flows-py). |
| **VZ file-handle gateway, as Devin uses** | Apple exposes a connected datagram network attachment. Devin exchanges Ethernet frames, answers ARP, validates addressing/source IP, passes accepted IP packets into a host tunnel, then applies host filtering and proxies. This provides a controlled routing boundary but adds gateway ownership; the attachment itself supplies no TLS substitution. Silo currently uses `VZNATNetworkDeviceAttachment`. Devin’s stated NAT rejection concerns a `pf` configuration race in its deployment, not a universal VZ limitation. [Apple API](https://developer.apple.com/documentation/virtualization/vzfilehandlenetworkdeviceattachment), [Devin networking account](https://devin.ai/blog/devin-gets-a-mac#enter-ethernet), [Silo engine.rs:485](/Users/polarzero/code/projects/microsandbox-workspaces/app/SiloUI/src-tauri/src/macos_computers/engine.rs:485). |
